GRIXIS COMMANDER ENCYCLOPEDIA 2 — ARCHIDEKT IMPORT PACKAGE
=========================================================

Cycle: global-restart-2026-10-13
Decks: 62/62 APPROVED + LOCKED

FASTEST USE
-----------
1. Open the decks folder.
2. Open the numbered TXT file for the deck you want.
3. Copy all lines.
4. In Archidekt, create/open a Commander deck and choose Import.
5. Paste the list and save/import.
6. The commander is placed first in each TXT. Mark/set it as Commander in Archidekt.
7. For Bjorna // Cecily + Lutri, set the intended commanders/companion manually.

FORMAT
------
Each individual file uses simple Archidekt-friendly lines: 1x Card Name
Set codes, collector numbers, and project role tags were intentionally removed.
The MASTER file is for reference/copying deck by deck; do not paste the entire MASTER file into one deck.

INTEGRITY
---------
60 decks were resolved by exact raw TXT SHA-256 match to current-cycle state/current_deck_overrides.json.
Two early-cycle decks (Admiral Brass, Unsinkable and Anhelo, the Painter) use state-explicit/current-cycle approved artifacts because their state canonical digests are logical/list digests rather than raw TXT file SHA-256 values.
All 62 source decks are current-cycle APPROVED + LOCKED, and each normalized export is structurally checked before packaging.
Frozen source exports and approved source artifacts were not modified.
