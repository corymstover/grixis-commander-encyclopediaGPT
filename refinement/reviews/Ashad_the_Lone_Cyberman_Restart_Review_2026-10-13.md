## Commander-first plan

Ashad gives the first **nonlegendary artifact spell** cast each turn casualty 2. The deck should convert expendable creatures into copies of high-impact artifact spells, while artifact tokens and sacrifice payoffs create value from entering/leaving the battlefield. Artifact cost reducers, repeatable artifact recursion, token-copy engines and death/ETB payoffs are central. The list must balance high-impact artifact spells with enough power-2+ creatures and artifact fodder to pay casualty.

## Changes

**Retained from prior review:**
- **Ultron, Artificial Malevolence for Dalek Drone.** Ultron can pay {2} when another nontoken artifact enters to create a token copy as a 1/1 Ultron Drone artifact creature in addition to its other types. It creates repeatable artifact-copy value; the token copy does not retrigger the nontoken-entry condition on itself. Dalek Drone's smaller one-shot token/tribal contribution is less valuable than the repeatable copy engine.

**Three new changes:**
- **Canoptek Spyder for Cursed Mirror.** Spyder is a five-mana artifact creature that draws a card whenever another nontoken artifact creature or Vehicle enters under your control. It can receive Ashad's casualty copy, and the copied Spyder increases draw from future nontoken artifact-creature entries. Cursed Mirror is a three-mana rock with a one-turn creature-copy effect; the deck has substantial ramp and several other copy engines, so the recurring draw engine is preferred. Trade-off: one fewer mana rock and a higher curve.
- **Cryptothrall for Twinning Staff.** Cryptothrall gives other artifact creatures you control hexproof. It is a nonlegendary artifact creature, so Ashad can copy it; two Cryptothralls protect each other and the artifact-creature board. Twinning Staff only multiplies instant/sorcery copies, while the deck's core copy engine is artifact-spell casualty. Trade-off: less explosive copying of the smaller instant/sorcery package.
- **Technomancer for Thopter Spy Network.** Technomancer is a nonlegendary artifact creature whose ETB mills three, then returns artifact creature cards from your graveyard with total mana value six or less. When cast as the first nonlegendary artifact spell with casualty paid, both the copy and original resolve with separate ETBs; each can reanimate a different set of artifacts. Thopter Spy Network provides slow ongoing Thopter production and combat-damage draw, but the deck already has multiple token engines and card-advantage sources. Trade-off: losing a reliable incremental draw/token enchantment for a seven-mana but potentially explosive recursion payoff. Artifact cost reducers materially improve the practical cost.

## Key rules interactions

- Ashad's casualty applies to the first nonlegendary artifact spell you cast each turn, including on opponents' turns if you can cast an artifact at instant speed (for example, with Shimmer Myr). You sacrifice a creature with power 2 or greater as an additional cost; the copy resolves before the original.
- Cryptothrall's static ability grants hexproof to other artifact creatures. If two are on the battlefield, each grants the other hexproof, and both protect the rest of the artifact-creature board from targeted spells/abilities. Hexproof does not stop untargeted board wipes.
- Canoptek Spyder's draw trigger requires another **nontoken** artifact creature or Vehicle to enter. When Ashad copies Spyder, the token copy does not cause the original Spyder to draw, but the token Spyder sees the original nontoken Spyder enter; each Spyder then triggers for future nontoken artifact-creature entries.
- Technomancer's copied ETB resolves separately for the token copy and original. Each mills three and can return artifact creature cards with total mana value six or less; the first resolution changes the graveyard before the second, so targets cannot be reused if they have already left the graveyard.
- Ultron's ability requires paying {2} and another nontoken artifact entering. Its token copy is a token and does not create a self-trigger loop.
- The deck's sacrifice payoffs (Disciple of the Vault, Mayhem Devil, Marionette Master, Pitiless Plunderer, Reckless Fireweaver and Ingenious Artillerist) can convert artifact-token creation and sacrifice into damage, Treasure or other value. Their triggers are not all interchangeable: some care about artifact ETBs, some about artifacts leaving the battlefield, and some about creature deaths.
- The existing Portal to Phyrexia, Noxious Gearhulk and Wurmcoil Engine are strong nonlegendary artifact casualty targets; copied artifact spells can produce multiple ETBs/death triggers, subject to the exact spell and available sacrifice fodder.

## Candidate review

The full-list matrix covers all 95 frozen baseline names plus four additions. The candidate ledger screens 30+ commander-specific alternatives, including Canoptek Spyder, Cryptothrall, Technomancer, Mishra, Eminent One, Missy, Royal Warden, Cybership, Anrakyr the Traveller, Jhoira's Familiar, Master of Etherium, Urabrask's Forge, Bloodghast, Buried Ruin, Archway of Innovation, Worldwalker Helm, Uthros Research Craft, and others.

- **Canoptek Spyder accepted:** repeatable draw tied to nontoken artifact-creature entries and a high-value casualty-copy target.
- **Cryptothrall accepted:** protects the artifact-creature engine and can be casualty-copied to create overlapping protection.
- **Technomancer accepted:** seven-mana ceiling is real, but the artifact cost-reduction package and casualty copy can produce two separate graveyard-reanimation ETBs. It is not treated as a guaranteed full-board reanimation; each ETB is limited to total mana value six.
- **Mishra, Eminent One rejected:** strong repeated artifact-copy engine, but it is a five-mana nonartifact legendary creature and overlaps Ultron, Brudiclad, Auton Soldier, Sculpting Steel and Phyrexian Metamorph. The selected artifact creatures more directly use Ashad's casualty mechanic.
- **Missy rejected:** high-ceiling death payoff, but six mana and its nonartifact-creature-death condition are less reliable in a list whose most common sacrifice fodder is artifact creatures; existing death/ETB payoffs are dense.
- **Royal Warden rejected:** copied ETBs create a fixed two Necron Warrior tokens each, but Spyder offers ongoing draw and Technomancer provides more consequential recursion; the deck already has multiple token producers.
- **Cybership rejected:** high-mana Vehicle whose token payoff requires combat damage and crew, so it is slower than Spyder/Technomancer.
- **Anrakyr the Traveller rejected:** powerful attack-triggered artifact recursion, but it is legendary and therefore does not receive Ashad's casualty 2; it also requires attacking to access the graveyard spell.
- **Jhoira's Familiar rejected:** cost reduction is useful but overlaps Foundry Inspector, Etherium Sculptor, Enthusiastic Mechanaut, Artificer Class and Tezzeret.
- **Master of Etherium rejected:** large artifact body/anthem is plausible but overlaps existing board scaling from Cyberdrive Awakener, Tezzeret and token-copy engines.
- **Urabrask's Forge rejected:** recurring combat token is useful fodder but is not an artifact token and is slower than the existing artifact-token engines.
- **Buried Ruin / Archway of Innovation rejected:** utility lands would increase colorless-land pressure in a 30-land three-color deck; Academy Ruins and Inventors' Fair already cover key artifact recursion/tutoring.
- **Technomancer vs. other recursion rejected alternatives:** Scrap Trawler, Emry, Goblin Welder, Academy Ruins and Portal to Phyrexia already provide recursion, but Technomancer was accepted because its copied ETBs can immediately return multiple artifact creatures.
- **Twinning Staff cut:** its copy multiplier is restricted to instant/sorcery spells, whereas the primary plan copies artifact spells; Cryptothrall contributes more to the board's survival.
- **Cursed Mirror cut:** useful ramp and one-turn copy, but the list has 20 ramp sources and several copy engines; Spyder adds repeatable card flow and is itself an artifact-casualty payoff.
- **Thopter Spy Network cut:** consistent value but redundant with Poetic Ingenuity, Simulacrum Synthesizer, Worldwalker Helm, Cybermen Squadron, Ultron and other token engines; Technomancer offers a stronger high-impact recursion line.
